# Uni Launcher app icon

The Uni Launcher mark, rendered from
[`docs/brand/unitexto-mark.svg`](../../docs/brand/unitexto-mark.svg) by `packaging/icons.sh`. Every file
in this directory is generated; do not edit the renders by hand.

- `artcraft-launcher.svg`: a copy of `docs/brand/unitexto-mark.svg`; also the hicolor scalable icon.
- `artcraft-launcher.ico`, `artcraft-launcher.icns`, `artcraft-launcher-1024.png`, `hicolor/`: renders.

The file names are kept from the upstream project. The mark belongs to Uniphar Indústria
Farmacêutica, all rights reserved: see [`LICENSE.txt`](LICENSE.txt).
