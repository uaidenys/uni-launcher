Uni Launcher portable mode

While this file sits next to artcraft-launcher.exe, Uni Launcher keeps its settings, its
download cache and its record of installed apps in the UniLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Uni Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Uni Launcher) instead.
If UniLauncherData can't be written (for example on a read-only drive), Uni Launcher says
so and uses %APPDATA%\Uni Launcher instead.
